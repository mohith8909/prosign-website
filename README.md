# Prosign Communications — Website

Single-page site for Prosign Communications, a Chennai advertising agency (est. 2008).

Open `index.html` in a browser — no build step. Images and logos live in `assets/`.

Some interactive sections (media globe, client wall, brief form) are ports of components from
[React Bits](https://github.com/DavidHDev/react-bits); see `assets/licenses/react-bits-LICENSE.md`.
Media and client logos are trademarks of their owners (sources in `assets/media/SOURCES.txt`).
